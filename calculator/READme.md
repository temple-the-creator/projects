# JavaScript Calculator

A simple calculator web application built from scratch using HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations
- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Decimal numbers
- Delete button
- Clear button
- Calculation using the equals button

## Technologies Used

- HTML5
- CSS3
- JavaScript

## What I Learned

While building this project, I practiced:

- DOM manipulation
- Event listeners
- `querySelectorAll()`
- `data-*` attributes
- Arrays
- Loops
- Functions
- `switch` statements
- String and number conversion
- Building and processing mathematical expressions
- Debugging JavaScript
